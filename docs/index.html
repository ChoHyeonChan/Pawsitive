주요 기능

실시간 산책 매칭

위치 기반으로 주변 산책 도우미와 보호자를 연결하고 요청 상태를 실시간으로 공유합니다.

GPS 산책 추적

산책 경로, 시간, 거리 데이터를 기록하고 보호자에게 산책 상황을 전달합니다.

AI 건강 분석

Gemini 기반 상담 흐름으로 증상, 생활 습관, 관리 방법을 안내합니다.

교육 콘텐츠

산책, 사회화, 리드줄 사용법 등 보호자에게 필요한 학습 콘텐츠를 제공합니다.

커뮤니티

반려견 일상과 산책 기록을 공유하며 사용자 간 소통을 돕습니다.

PAW 포인트

서비스 활동과 결제 흐름을 포인트 시스템과 연결해 플랫폼 경험을 확장합니다.

기술 스택

  • Frontend: HTML, CSS, Vanilla JavaScript
  • Backend: Node.js, Express
  • Realtime: Socket.IO
  • AI: Google Gemini API
  • Auth: Passport.js OAuth
  • Payment: 토스페이먼츠
